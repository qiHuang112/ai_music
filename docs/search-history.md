# 首页搜索历史

## 本轮需求（2026-09-27）

- 首页搜索框一获得焦点，下方只显示历史搜索记录，隐藏“我的音乐”、歌单、榜单和匹配歌单入口；返回键直接退出聚焦态。
- 历史项采用横向自动换行的紧凑文字卡片，间距和内边距很小，类似音乐榜单关键词。
- 长按任一历史项进入删除状态，所有项显示删除按钮；点项可再次搜索。
- 歌曲与歌单搜索分别记忆真正提交的关键词，按最近使用排序，重复搜索置顶；记录保存在本机。

## 试用场景

1. 搜索歌曲和歌单各一个关键词，再次聚焦及切换模式时，只看到当前模式的历史卡片。
2. 点击卡片复用关键词并显示搜索结果；长按进入删除状态，删除单项后再次聚焦确认不会回来。
3. 搜索结果页聚焦输入框时原内容隐藏，返回只收起焦点，原结果仍可查看；再返回才清除搜索。
4. 无历史时聚焦，页面显示空态，首页其它模块不占位。
