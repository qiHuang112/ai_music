# 2026-10-12 开发记录

本仓库已由新用户 fork 后在自己的 Mac 上使用，主要跑 iPhone。用户要求把界面重做成“黑胶唱片的复古感 + 现代的界面、交互和效果”，先只适配 iPhone，先搭设计系统。约定见[设计系统](../design-system.md)。

## 本轮完成

- `app_theme.dart`：薄荷绿换成暖黑、封套米白、琥珀色板；新增 `MusicTokens`（主题扩展）、`MusicMotion`、`MusicType`，清掉 Material 的拉丁字距。`MusicAppTheme.create` 签名不变，现有页面只跟着换色，布局未改。
- `lib/src/presentation/design/`：烟熏玻璃、唱片与转动惯性、唱机与唱臂、封套、氛围背景与胶片颗粒、封面取色、按压/播放键/进度条/音柱等控件，以及设计系统预览页。
- `main.dart`：`--dart-define=AI_MUSIC_DESIGN_GALLERY=true` 时启动到预览页；不带该参数行为不变。
- 新增 `test/design_system_test.dart` 5 项：主题令牌、320 宽 1.6 倍字号下预览页无溢出、播放与明暗切换、唱片停转后动画结束、进度条点按与拖动。

## 验证

- `flutter analyze` 无问题；全量 Flutter 测试 894 项通过（原 889 项加新增 5 项）。未跑 Python 测试，未构建 Android。
- iPhone 17 Pro 模拟器（iOS 26.5）运行带预览参数的 debug 包，逐屏检查了深色与浅色下的唱机、色板、字体、玻璃三档、封套、控件、列表样例；Bodoni 72 与 DIN Alternate 系统字体按名称生效。未在真机验证，模糊的帧率未测。
- 本机 Xcode 27 下 `flutter build ios --simulator` 在多架构校验一步失败（新版 lipo 不接受多个架构参数），改为 `xcodebuild` 只编 arm64 并在命令行把部署目标提到 15.0；工程文件未改。

## 过程中的问题

- 预览包第一次运行时进度条的无障碍标注不完整（有增减动作却没有增减后的值），框架每帧断言，约一分钟内向应用的操作日志写入五千多条报错，把当晚更早的日志滚动挤掉了。已补全标注并加测试，之后的运行无报错。
- 懒创建的动画控制器在从未使用就销毁时会在 `dispose` 里才创建并触发断言，测试发现后全部改到 `initState` 创建。
- 换包后模拟器里的缓存索引 `_cache_index.json` 为空，而缓存目录里的音频文件还在；数据容器没有变，原因未查明，本轮没有改任何缓存代码。在真机上装新包之前需要先弄清楚。

## 用户反馈：白天模式用奶油薄荷色

用户看过预览后要求白天模式改为奶油薄荷色。第一版做成浅薄荷背景配奶油面板，用户随即明确“奶油做底、薄荷只做点缀”；最终浅色色板是奶油背景与面板、薄荷主色和选中底、墨绿文字，白天背景的光减到很淡，夜间的暖黑与琥珀不变；色板新增 `haze`（没有封面时背景的第二团光），浅色玻璃的阴影改用文字色。预览页启动时跟随应用当前的明暗设置。全量 894 项与分析再次通过；模拟器上看过浅色的预览页和首页，截图在 `docs/design-system/`。

## 用户确认方向后：分支、字体、播放器、Tab 栏

用户确认整体方向，同意带字体包、加底部 Tab 栏和开分支，并要求把不合理的交互和布局改掉。

- 新建分支 `ui-vinyl`，未提交。

- 播放器：唱机取代方形封面，背景取封面的颜色，歌词预览去掉卡片，进度条改细，播放控制换成玻璃键并在窄屏整体缩放；调整间距后一屏放得下，“切换来源／热评”不再被挤到屏幕外。从迷你播放条向上滑出。保留了原有的 `Slider`、`AppBar` 和全部 key。
- 迷你播放条改用玻璃组件。
- 首页变成四个 Tab 的外壳（首页／音乐库／下载／设置），原右上角三个图标取消。
- 新增 `test/flutter_test_config.dart`，测试里关闭持续动画。
- 因导航有意改变而调整的测试：5 处（返回键改为点首页 Tab、Tab 栏占位后列表项在 600px 测试画面之外、Tab 标签与页面标题同名、收藏后下载转圈持续显示所以不能等它停、热评入口需滚入视野）。断言的行为没有放宽。
