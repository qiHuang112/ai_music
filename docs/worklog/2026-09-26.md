## 开发与自测

- **截图导入与并行处理**：按用户反馈放宽截图候选的默认选择规则；多图 OCR 最多三张并行，在线搜歌按空闲槽位补位。设置页提供 1～10、默认 3 的搜歌并发滑块。保留同词请求共享、源站限速和 429 后暂停。
- **播放与下载**：修复未缓存歌在源凭据过期时的有界刷新、下载后页面整屏加载、加密 `.mflac` 无法播放时的精确同曲 MP3 回退；加入自建歌单批量下载、下载管理进度和并发数设置。WiFi 自动下载后来收敛为歌单内容未变时 24 小时内一次；首次进入才显示自动批次进度，后续自动下载静默，手动下载仍显示进度。
- **歌词**：根据手机当前曲目逐首定位真实原因，包括把音频 URL 误存为歌词、连写时间标签、片头署名导致纯文本被丢弃、重复歌词过滤过严、跨源同录音匹配缺失。播放时预取后面三首歌词，不限制 WiFi 或移动网络。对于《Best Laid Plans / Restos》，精确歌词接口和网页 LRC 按钮都未给出可信歌词，因此没有借用其他录音的歌词。
- **播放控制**：顺序播放到列表末尾回到第一首，Android 播控中心增加播放模式按钮；播放器页与底部播放栏支持左右滑动切歌。
- **发现榜单首版**：首页展示 QQ 六榜和网易云四榜，支持查看实时排名并选择歌曲加入自建歌单；QQ MV 榜只展示视频排名。首版手机体验包 versionCode 6106，后续体验调整见次日日志。
- 每个可体验候选都运行了与改动相关的测试、静态分析，并按需构建保留数据安装包。当天末尾榜单候选的完整 Flutter 测试为 301/301；中间验证记录不等同于最后代码的验证。

## 用户体验与独立 review

- **截图/播放基础能力**：用户验收后，review 覆盖 OCR、缓存/预取、平台播控与相关测试；修复审查发现的问题后确认无阻断项。对未缓存歌的快速 A→B→A 点击补了请求身份回归，防止旧请求更新当前页。
- **歌词与加密音频**：review 指出损坏 LRC 侧文件可能阻断补词、HTML 响应可能冒充歌词、加密音频回退只看第一个平台且可能选未验证的加密品质。补充边界检查与回归测试后通过复审。后续歌词预取 review 又修复失败后不能重试、以及预取结果压过新本地 `.lrc` 两个问题。
- **并行搜歌**：review 找到同词在途请求受源站封锁误拦、乱序完成误算连续失败两个时序问题；两者有受控测试并通过复审。
- **歌单自动下载**：review 找到 WiFi 短暂断开后旧任务结算、进度通知早于批次登记、进程退出后尝试记录、歌单变更与批次快照不一致等边界；以持久化 pending/completed 状态、冻结批次快照及相应时序测试修复，相关独立测试 122/122，通过复审。
- **播放模式与滑动**：review 分别找到了快速点播放模式时的状态竞态、手动切歌重复发布媒体项；修复并补回归后均无剩余阻断项。

用户对每轮体验包的反馈推动了上述交互调整；开发与 reviewer 的测试结论不等于用户对最终体验的验收。更细的单曲诊断、当时安装包哈希及中间测试结果保留在 Git 提交 `67f6e85` 的 `CURRENT_STATE.md` 和相应功能文档中。
