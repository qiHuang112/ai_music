# 设置页整理（2026-09-27）

- 首页设置按“通用、音乐与下载、存储、高级”分组；语言和换肤、音乐源和默认下载品质、播放缓存和已下载首数分别相邻。
- 截图搜歌并发与歌单下载并发集中到“并发设置”子页；首页只显示两项当前数量，不再直接铺开两个滑块。原 1～10 范围、保存时机及实际任务行为不变。
- 局域网音乐库放在高级分组。所有现有入口继续可达，清除缓存仍保留确认对话框，语言切换后分组标题和新入口也同步切换。
- 用户试用 8140 后指出分组大标题偏小、行列错落。视觉调整为分组卡片，标题放大并与每行主标题对齐，卡片和行内留白统一；并发子页沿用同样的卡片容器。只调整视觉层级，不改设置值或交互。

## 试用场景

1. 设置首页能快速找到常用项，两个并发滑块不占用首页高度。
2. 进入并发设置后，两种并发项都可调整并保存；返回首页显示新数量。
3. 默认下载品质、缓存清理、LAN 地址及语言/换肤的既有操作不受分组调整影响。

2026-10-08：音乐来源默认FLAC并置于首项；说明覆盖搜索、匹配及未缓存播放，解释本地缓存和单曲手选优先。设置切源覆盖旧队列、后台匹配与下载，见 [源设置规则](source-preferences.md)。


## 2026-10-09 最新调整

保留新版设置页的分组及普通当前值排布，语言「中文」与其他设置值一致展示，设置首页不显示语言单选状态；只有进入语言子页才标记实际当前语言，仍可切换和保存。正在播放页恢复原先居中封面、歌名与歌手的结构，收藏与歌曲热评相邻放在顶部；进度条和模式／上首／播放暂停／下首／当前队列五播控固定在底部，短屏只滚动歌曲内容。歌词页保持当前已确认设计，其他页面不扩大改动。试用检查包括：设置初始／返回语言子页无常驻选中背景，播放页窄屏大字／横屏五播控可达、热评入口打开正确歌曲、歌词与队列正常。

实机复现：从语言页返回时，已点过的行恢复焦点高亮。值行打开子页前释放当前焦点，保留键盘遍历和语言真实选中值。回归测试修复前失败、修复后通过。

投屏实机还观察到鼠标悬停色会在返回后保持，移动到手机内空白处即消失。设置值行禁用悬停底色，仍保留按压反馈和键盘焦点反馈。
