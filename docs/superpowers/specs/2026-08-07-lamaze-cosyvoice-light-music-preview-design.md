# 拉玛泽 CosyVoice 女声与轻音乐试听重制设计

## 背景与问题结论

现有四首拉玛泽引导曲的功能和局域网同步已经通过验收，但音频本身未达到可用标准：

- 语音生成代码把 `Grandma (中文（中国大陆）)` 错误截断为 `Grandma`，单条生成结果约为 0.016 秒、约 -91 dB，实际等同静音。
- 后续试听的 macOS/Windows 系统女声虽然能够听清，但语气僵硬，不符合温柔、自然的真人感要求。
- 现有背景使用通用 SoundFont 和规则化 MIDI 琶音，音符与力度过于机械，不像干净、舒缓的轻音乐。

本设计是 `2026-08-06-lamaze-audio-redesign-design.md` 的替代性补充。凡旧设计中涉及 macOS `say`、Windows SAPI、MuseScore General、FluidSynth 或通用 MIDI 作为正式成品声源的内容，均由本设计覆盖并废弃。

## 已确认的决定

- 人声使用开源 CosyVoice，以官方 `CosyVoice-300M-SFT` 的 `中文女` 预置声线作为清晰度基线；如需进一步控制温柔、平静的语气，则在试听阶段改用官方 CosyVoice Instruct 模型。
- 不克隆网上陌生人的身份或个体声纹，不拼接公共语料中的单字和短句。
- 背景方向为舒缓钢琴加柔和弦乐铺底。
- 不使用鼓点、明显低频脉冲、鸟鸣、流水、白噪声、铃声或机械逐拍琶音。
- 只先制作约 45 秒的《01-慢呼放松》试听；试听未通过时不生成或替换四首正式成品。
- 音频开头不报幕、不介绍用途；音乐进入后直接给出当下动作提示。

## 试听内容与结构

试听总长目标为 45 秒，允许误差不超过 0.1 秒：

1. 前 4 至 6 秒仅有钢琴和极轻弦乐，使听者自然进入氛围。
2. 第一条口令直接使用“肩膀松下来，下巴也松下来。”
3. 中段使用“轻轻吸气……慢慢呼出去。”，停顿由音频时间轴控制，不依赖 TTS 朗读省略号。
4. 后段使用“跟着自己的节奏，放松就好。”
5. 最后保留自然延音，不截断人声或乐器尾音。

试听只用于确认四件事：女声自然度、普通话清晰度、语速与停顿、音乐和人声比例。试听通过后，四首完整版继续沿用已经审核过的短句式动作引导和医疗安全边界。

## CosyVoice 人声管线

- 使用官方仓库和官方模型文件，记录仓库版本、模型标识、下载来源、许可证和 SHA-256。
- 以 `中文女` SFT 声线为第一候选；若其语气仍显僵硬，则使用 CosyVoice Instruct 模型生成同文案对照样片，不使用 macOS `say` 或 Windows SAPI 作为正式回退。
- 每条口令独立生成，避免长段落出现速度漂移、吞字或不自然情绪变化。
- SFT 样片通过标点、分句、停顿和后期时间轴控制节奏；Instruct 样片才使用温柔、平静、清楚的语气指令。两种模式均不得采用广告腔、播音腔、夸张耳语或甜腻角色音。
- 在混音前逐句检查：无错读、漏字、重复、爆音、异常静音和句尾截断。
- 若某句不合格，只重生成该句；所有句子通过后才进入混音。
- 输出人声干声保留原始文件，并另行生成 48 kHz 单声道工作文件，便于复核和重新混音。

## 钢琴与弦乐管线

- 正式成品不再使用 MuseScore General、General MIDI 音色或程序化逐拍琶音。
- 从明确标注为 CC0、公共领域或许可允许改编与导出成品的来源选择真实录制质感的钢琴和弦乐素材。
- 优先使用独立音符、和弦或短氛围 stem 重新编排，避免直接截取可辨认的完整商业歌曲或旋律。
- 钢琴使用稀疏和弦与少量单音回应，不持续填满每一拍；弦乐以长音和缓慢动态变化托底。
- 素材来源 URL、作者、许可证、下载日期和文件 SHA-256 写入交付元数据；许可不清楚的素材不进入试听。
- 试听编曲保持原创结构，正式四首曲目可复用同一音色体系，但旋律、和声密度和动态应按曲目用途调整。

## 混音设计

- 人声居中、清晰靠前，不添加明显回声；只允许极轻的均衡、压缩和去齿音。
- 人声出现时，钢琴与弦乐整体平滑降低约 4 dB；口令结束后缓慢恢复，不能产生明显抽吸感。
- 钢琴避免尖锐高频，弦乐避免浑浊中低频，人声频段不得被铺底遮挡。
- 试听输出 48 kHz、24-bit WAV 和 192 kbps MP3。
- 真峰值不高于 -1.5 dBTP，无削波、无异常长静音，手机扬声器上仍能听清每个字。

## 医疗与文案边界

- 音频是呼吸陪伴工具，不替代医生或助产士的现场判断。
- 不根据宫口厘米数自行判断阶段，不承诺无痛或顺产，不要求长时间闭气。
- `03-暂缓用力` 仅在医护明确要求暂缓用力时使用。
- `04-跟随医护` 不自行下达用力指令，现场医护指令始终优先。
- 安全说明保留在 TXT、README 和 JSON 中；音频中只说当下需要执行的简短动作。

## 验收与发布关卡

试听交付前执行以下检查：

- CosyVoice 生成文件时长合理且可解码，不得再次出现近零长度静音。
- 三句文案全部真实出现在音频中，人工逐句核对清晰度。
- 背景听感为干净、舒缓的钢琴和弦乐，无机械 MIDI 感和明显杂质。
- 45 秒 WAV/MP3 的时长、采样率、码率、峰值和响度符合规格。
- 在耳机和手机扬声器分别试听，人声均不被音乐遮盖。

用户试听后可以分别对“人声”“音乐”“语速”“音量比例”提出通过或修改意见。只有四项全部通过，才生成四首完整版；完整版验证通过后再原子替换 `E:\music\Lamaze\`，保持现有四个稳定歌曲 ID 和 `Lamaze` 歌单映射不变。

## 非目标

- 本轮不修改 Flutter 客户端、局域网 API、歌单映射或 APK。
- 本轮不自动同步到手机；45 秒试听先在 Codex 中直接播放验收。
- 本轮不付费购买音乐或配音服务，不使用授权状态不明的“免费下载”素材。
