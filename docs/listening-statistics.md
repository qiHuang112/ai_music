# 我的听歌（2026-10-06）

用户同意第一版需求并开始实现：入口只放音乐库，首页不增加统计；歌曲/歌单排行榜默认按有效播放次数，可切换累计时长。

范围：今天/昨天/近7天/近30天/累计/自选日期，实际听歌时长、不同歌曲、有效次数、听歌天数及连续天数；按日趋势（大范围按月/年汇总）、歌曲及歌单排行、某日听歌记录与播放/现有歌曲操作、歌单详情跳转。沿用公共薄荷明暗主题、小屏/大字/中英文适配。歌手/时段分布/分享年报以后再做。

口径：实际播放才计时，暂停/缓冲/错误/下载/预缓存/后台匹配不计；拖动进度不把跳过部分计时。满30秒为一次有效播放；总时长不足30秒的歌曲，听满一半算一次。暂停继续、同歌元数据/音源更新不重复计次；自然循环新一轮可再次累计一次。跨午夜拆到实际本地日期，有效次数归达标时所在日。有效次数与时长独立，短听也保留实际秒数。不同歌曲数按实际听到的内容去重。

歌单归属：只记实际发起播放队列的歌单，锁屏/通知/自动下一首/队列点选保持来源；搜索/本地单曲无所属歌单。多歌单包含同曲不多记，打开歌单不算听。切源沿用原逻辑歌曲ID，缓存的同源品质版本复用可靠歌曲身份；不靠模糊歌名合并不同Live/翻唱。历史保留名称/封面/播放关联快照，已删除内容无法播放时提示。

数据：本机独立保存，不迁移/伪造旧playlist_usage打开/播放启动记录。统计从启用后开始，页面显示起始日期。月文件保存实际记录，年份/月份折叠和按需列表避免365天铺开。清空统计单独确认，不删歌单/收藏/音频；不中断正在播放。计时不订阅整张歌曲列表，写盘批量串行/原子保存，后台仍计时；异常不阻塞播放，界面可重试。每秒采样、10秒批量落盘及暂停/切歌/后台时检查点，强制杀进程可能丢最后一个短检查点间隔，不补造播放时长。

验收：播放10分钟暂停5分钟计10分钟；缓冲无累计；拖到末尾不增加被跳过时长；短听不增加次数；暂停恢复只一次；跨午夜分日；单曲循环两轮可计两次；后台/锁屏、手动/通知切歌、快速选源失败、播放列表追加、重启保存和清空并发；排行/日期过滤/年度折叠/长列表滚动/删除内容/明暗语言大字。
