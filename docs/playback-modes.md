# 播放模式

2026-09-26 用户要求保留三种可切换模式：顺序播放、单曲循环、随机播放。顺序播放按当前队列原顺序前进，最后一首结束后从第一首继续；只有一首时也继续循环。App 播放页和系统播控中心使用同一切换顺序：顺序播放 → 单曲循环 → 随机播放 → 顺序播放。

Android 播控中心的控制列表是收藏、上一首、播放/暂停、下一首、播放模式。播放模式是第五个自定义动作，点击后调用同一控制器切换逻辑，图标和文案反映当前模式。系统通知紧凑视图仅配置原来的三个位置；小米系统实际可见槽位由系统界面决定，需以真机展示为准。鸿蒙系统传入的 `sequence` 和 `list` 都归一为新的顺序播放，向系统发布列表循环状态。
