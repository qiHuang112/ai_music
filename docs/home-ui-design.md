# 首页视觉优化（2026-10-06）

用户在三个可交互首页预览中确认“清爽列表”，本轮先落实首页。参考 Impeccable 的原生产品可读性与一致性原则，以及 Taste redesign 对既有功能和框架的保留原则；继续使用 Flutter Material，不引入网页 UI 或装饰动画。

## 已确认布局

- 顶部“我的音乐”放大，下载、歌单管理、设置及更新红点保持可达。
- 搜索使用浅色圆角容器；左侧显示歌曲/歌单切换，右侧保留截图搜歌和搜索按钮。切换不重排下方内容。聚焦仍只显示对应类型的历史记录，返回退出聚焦。
- 收藏作为独立紧凑入口；常听歌单最多四行，带缩略封面、一行名称和歌曲/同步摘要，管理入口放在分组标题右侧。空歌单仍能创建。现有常听排序和进行中同步优先规则不变。
- 发现按 QQ 音乐、网易云分组，榜单使用紧凑按钮，去掉重复大卡片和副标题。
- 底部播放条使用已有封面与统一留白；既有点开详情、播放/暂停、上/下一首和左右滑动继续有效。播放条只在有歌曲时出现，搜索聚焦时隐藏。
- 缩略图复用已存歌曲/原歌单封面，缺失或加载失败显示统一占位；不额外搜索封面、不改歌曲归属或触发下载。按设备像素限制图片解码尺寸。

## 10158试用反馈与下一步对齐

- 用户要求绿色更明亮、有小清新感觉：搜索按钮改为亮薄荷绿与深色图标，浅色底减少灰感，文字用可读的深绿色；深色模式同样使用更清新的绿调。
- 预览与实际功能的主要差异：预览顶部“播放列表”示意当前队列，实际顶部打开缓存/自建/匹配歌单的音乐库；预览底部有当前队列入口与细播放/缓冲条，实际底部保留上/下一首、播放暂停，尚无队列列表与迷你进度条。详情页已有播放/缓存进度。
- 用户最新决定：先把更明亮的配色安装到77，先定整体风格；当前播放队列与迷你播放/缓存进度等风格定好后再开发。本轮仅交付配色，不新增这两项功能。

## 验证场景

1. 320dp 窄屏、深色模式和放大字体下，长歌单名/英文名称不挤压搜索与操作按钮，无横向溢出。
2. 点击收藏、歌单、管理、两个平台的榜单和三项顶部入口，原功能可达。
3. 歌曲/歌单切换后首页歌单区域不跳动；聚焦显示历史，返回恢复；长按删除仍可用。
4. 没有封面、封面失败、空歌单均有可用占位和入口；正在同步的状态文字继续出现。
5. 播放条不占无播放状态的首屏；有播放时可以滑动切歌、控制播放和进入详情。
