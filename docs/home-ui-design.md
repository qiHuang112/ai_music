## 10158试用反馈与下一步对齐

- 用户要求绿色更明亮、有小清新感觉：搜索按钮改为亮薄荷绿与深色图标，浅色底减少灰感，文字用可读的深绿色；深色模式同样使用更清新的绿调。
- 预览与实际功能的主要差异：预览顶部“播放列表”示意当前队列，实际顶部打开缓存/自建/匹配歌单的音乐库；预览底部有当前队列入口与细播放/缓冲条，实际底部保留上/下一首、播放暂停，尚无队列列表与迷你进度条。详情页已有播放/缓存进度。
- 用户最新决定：先把更明亮的配色安装到77，先定整体风格；当前播放队列与迷你播放/缓存进度等风格定好后再开发。本轮仅交付配色，不新增这两项功能。
