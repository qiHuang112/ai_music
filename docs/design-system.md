# 设计系统：黑胶 × 玻璃（2026-10-12）

用户要求把界面重做成“黑胶唱片的复古感 + 现代的界面、交互和效果”，不是纯古典；先只适配 iPhone，先把设计系统搭出来再改页面。本文件是这套设计系统的约定，取代 [全应用UI](app-ui-style.md) 里的薄荷绿配色；那份文档里的功能对齐和验证记录仍然有效。

预览：用 `--dart-define=AI_MUSIC_DESIGN_GALLERY=true` 启动，应用会打开设计系统预览页，右上角箭头进入正常首页。截图见 [design-system/](design-system/)。

## 一句话

一间听音室。夜里是暖黑的房间和电子管的琥珀光；白天是奶油色的纸，一种嫩叶绿只做点缀。唱片、唱臂、封套是画出来的实物；承载它们的界面是烟熏玻璃、弹簧动效和跟着封面变化的光。

## 两条规则

1. **印刷品是方的，玻璃和金属是圆的。** 封面、封套圆角 6；按钮、播放条、弹层用大圆角或全圆。
2. **每个模式只有一种亮色。** 夜里是琥珀，白天是嫩叶绿，只给“正在发生”的东西：播放键、进度、当前行、选中项。其余靠明度区分，不再加第二种强调色。标签红只用于收藏和破坏性操作。

## 色彩

定义在 `lib/src/presentation/app_theme.dart` 的 `MusicPalette`。页面仍然只从 `Theme.of(context).colorScheme` 取色；`ColorScheme` 没有对应角色的几种颜色（标签红、黄铜、唱片、玻璃、高光）通过 `MusicTokens.of(context)` 取。

| 角色 | 夜（深色，默认） | 昼（浅色，奶油底配嫩叶绿） |
| --- | --- | --- |
| 背景 | `100E0C` 暖黑 | `FAF7F1` 奶油白 |
| 面板 | `1C1915` | `FFFDF8` |
| 输入框 | `27231E` | `F1EBDF` |
| 选中底 | `362A18` | `E2F0CD` 浅绿 |
| 分隔线 | `332D26` | `E6DECF` |
| 正文 | `F4EDE0` 米白 | `23262B` 墨色 |
| 次要文字 | `A89E8F` | `6A6E73` |
| 主色（按钮底） | `E8A33D` 琥珀 | `A6D06F` 嫩叶绿 |
| 主色字（图标、链接） | `F2B866` | `47761C` |
| 标签红 | `D9573C` | `D9573C` |
| 黄铜 | `CDB98F` | `B09A68` |
| 第二团光 | `D9573C` 标签红 | `F3E6CE` |

没有纯黑、纯白和中性灰。唱片在两种模式下都是黑的。白天的配色取自用户 2026-10-12 给的参考图（灰调天蓝背景上一张奶油色卡片、墨色字）：先后试过浅薄荷底和奶油底配薄荷，用户一度选定奶油底配天蓝，2026-10-13 又按新给的色样改为偏黄的嫩叶绿。这种绿只出现在主色按钮、进度、选中底、图标和小标签上，背景的光压得很淡。夜间保持琥珀。

**封面取色**：`ArtworkPalette.of(图片)` 读出封面的主色和最鲜艳的颜色，`glow` / `shade` 给背景的两团光，`label` 给唱片中心的标签。取色结果按图片缓存。没有封面时用色板的主色和第二团光：夜里琥珀，白天是很淡的一点绿加浅杏。

## 字体

三种声音，定义在 `MusicType`。都用 iOS 自带字体，不增加安装包体积。

| 声音 | 字体 | 用在哪 |
| --- | --- | --- |
| 印刷 | Bodoni 72（中文回落到苹方） | 页面大标题、正在播放的歌名：`MusicType.masthead` |
| 正文 | 系统字体（SF + 苹方） | 列表、按钮、说明：`Theme.textTheme` |
| 刻字 | DIN Alternate | 分区小标签 `MusicType.eyebrow`；时间、数量、音质 `MusicType.readout`（等宽数字） |

主题里把 Material 给拉丁文加的字距清零了，中文不再显得松散。

中文大标题用随包的思源宋体 Bold（`assets/fonts/SourceHanSerifCN-Bold.otf`，约 12MB，SIL OFL 许可，许可文件同目录），西文和数字仍是 Bodoni 72。用户 2026-10-12 同意带这款字体。

## 材质

- **烟熏玻璃** `GlassSurface`：模糊并提高背后内容的饱和度，盖一层暖色，顶边一道高光，阴影只画在玻璃外侧。三档：`thin`（按钮）、`regular`（播放条、导航栏）、`thick`（弹层、菜单）。每块带模糊的玻璃是一次单独的合成，一屏控制在几块以内；已经放在玻璃上的控件传 `blur: false`。
- **宣纸** `PaperTexture`：白天模式的页面底是宣纸表面的纹理：密密一层压平的短纤维，多数顺着一个斜向，每根一侧是淡影、一侧是高光，看上去是微微的凹凸而不是画出来的线；没有长纤维。按用户 2026-10-12 给的参考图（近白的纸面、细密的毡状起伏）做，一张可无缝平铺的贴图只生成一次。夜间不加。
- **页面底** `PageBackdrop`：每个页面背后都有一层底：白天是奶油白加宣纸，夜间是暖黑加左上琥珀、右下标签红的光和胶片颗粒。它画在页面内容的下面（由主题里的页面转场给每个页面垫上，`Scaffold` 和 `AppBar` 本身透明），所以主色的按钮和图标保持实心，排在最前面。夜间的卡片、输入框、标签是半透明的烟色，房间的光会透过它们（用户 2026-10-13 明确：橙黄色在最上层，其余保持透光的样子）；对话框、弹层和菜单仍是不透明的面板色。固定在顶部、下面有内容滚过的条（歌单页标题栏、日期分组标题）用 `BackdropSlice` 画出自己背后那一块底，既遮住滚动内容又不出现色块接缝。
- **柔边** `SoftEdgeScrollBehavior`：所有竖向列表的上沿，内容滚到顶栏下面时在约 30pt 内渐隐，不再被一条硬线切断；没滚动时不生效，也不占性能。这是渐隐，不是 iOS 那种真正的渐进模糊。用户 2026-10-13 要求去掉顶栏下的分割线。
- **氛围背景** `AmbientBackdrop`：底色、两团缓慢游走的光、一层胶片颗粒、暗角。长列表后面关掉游走（`drift: false`）。
- **唱片** `VinylDisc` / `SpinningVinyl`：纹路、曲间空白、内圈、固定不动的反光、随转动的中心标签（放封面）。转动有惯性：起转约 0.3 秒，停转约 0.7 秒滑行。
- **唱机** `Turntable`：唱片加唱臂。播放时唱臂摆入落下，并随进度从外圈走向内圈；暂停时抬起回位。
- **封套** `RecordSleeve`：封面做成印刷封套，唱片从开口滑出一截；播放时滑出更多并转动。

## 控件

`lib/src/presentation/design/controls.dart`：

- `Pressable`：按下缩小、松开弹回、带触感，所有可点的自定义控件都包它。
- `PlayPauseButton`：播放键，实心、受光渐变、按下缩小回弹；播放时外发光更强，并以约 2 秒一个来回缓缓呼吸，暂停时收住。播放器和迷你播放条都用它。按钮、标签和卡片都是平的，没有投影；只有播放键带发光，悬浮的玻璃条（迷你播放条、Tab 栏）带阴影。
- `GlassIconButton`：圆形玻璃键，选中时点亮成琥珀。
- `GrooveSlider`：进度条，平时是一条细线，按住变粗，每 10% 一下轻触感，带缓冲进度。点按在松手时跳转。
- `EqualizerBars`：列表里标记正在播放的行。
- `LabelChip`、`QualityBadge`（FLAC / 24BIT / 320K）、`EyebrowLabel`、`SectionHeader`。

Material 自带的按钮、输入框、弹层、菜单继续由 `MusicAppTheme` 统一着色。

## 形状与动效

圆角在 `MusicUi`：封套 6、控件 14、玻璃 28、按钮全圆。

时间在 `MusicMotion`：快 140ms、常规 260ms、慢 460ms；触摸反馈用弹簧（`snappy` / `bouncy`），布局变化用曲线（`standard` / `emphasized`）；唱片一圈 8 秒。

持续动画（唱片、背景游走、音柱）遵守系统的“减弱动态效果”。Widget 测试里把 `MusicMotion.perpetual` 设为 `false`，否则 `pumpAndSettle` 不会结束。

## 导航

底部是四个文字 Tab：首页、音乐库、下载、设置（样式见“迷你播放条与底部导航”）。原来首页右上角并列的三个图标取消。迷你播放条停在 Tab 栏上方，内容从两者后面滚过。非首页的 Tab 第一次进入时才创建；系统返回键在其它 Tab 上先回首页。下载进行中时“下载”图标换成转圈，有更新时“设置”图标带红点。搜索框聚焦时两条栏都收起。

在播放器里点播放，先落唱针（约 0.3 秒），唱针到位后唱片起转、音乐同时开始；暂停是立刻的，唱针抬起，唱片滑行停下。用户 2026-10-12 要求这个顺序，并要求动效更快：唱臂 320ms、起转 280ms、停转 700ms。

播放器从迷你播放条向上滑出，一屏放得下全部内容：唱机（封面是标签，唱臂随进度走）、歌名、三行歌词、进度、播放控制、切换来源和热评。背景的光取自封面。

## 迷你播放条与底部导航

用户 2026-10-13 给了网易云的参考，要求照它的样子弱化导航、重做播放条。

- **播放条**：一条玻璃胶囊（高 54，烟熏玻璃：模糊背后内容、暖色罩面、顶边高光），悬浮在页面内容之上，背后没有底条。左端是和它等高的小唱片（封面占大半，播放时转），外圈是进度环，12 点起顺时针。中间一行“歌名 - 歌手”，顶边正中一道短横条提示可以上拉。右端的播放键：夜间是琥珀色的发光键，播放时它的光缓缓呼吸；白天是描边的小圆键（用户要求白天不改按钮颜色）。没有下一首和队列按钮：左右滑切歌，上滑或长按打开全屏队列，点一下进播放器。所有带播放条的页面都一样。中途做过一版实心面板色加描边播放键，用户要回了玻璃和主色键。
- **底部导航**：只有文字，当前项加粗加深，其余是灰色；下载进行中时“下载”旁有个小转圈，有更新时“设置”旁有红点。只有导航这一条有毛玻璃：后面滚动的内容被模糊并罩一层页面色。

## 当前队列

全屏弹层。每行右侧是“移出队列”和拖动排序的把手；顶部有批量操作（勾选后一起移出）和清空。正在播放的那首不能移出也不能拖动，清空会保留它。从队列移出不影响歌单和已下载的文件；歌单还在后台匹配时，被移出的歌不会再被自动加回队列。

## 列表

歌曲行左侧是封面（没有封面时是歌名首字的色块），点封面或点整行都播放；正在播放的行在封面上盖一层音柱，准备中是转圈。原来那颗单独的播放圆钮取消了，它和点整行是同一个动作。还没缓存的歌只是略淡，不再淡到像不可用。

歌单页在列表上方放一张封套（歌单封面，唱片露出一截，正在播放这张歌单时滑出更多并转动）、歌曲数和“播放全部”。它始终存在，进入多选或搜索时歌曲行不会跳动。

页面标题、分区标题和对话框标题统一用印刷字体（`titleLarge`、`headlineSmall`）。音乐库顶部“收藏／本地”是并排两块等宽的平面入口：左边图标和名称，右边用刻字体写歌曲数，中性底色，没有投影。

## 范围与后续

已完成：设计系统、播放器与歌词页、迷你播放条、底部 Tab 栏、歌曲行、歌单页封套头部、全局标题字体。首页内容区、下载管理、设置的版式保留原样，只换了颜色和标题字体。弹层、菜单和对话框保持不透明的面板色：它们承载长列表和表单，不做模糊。

未做：真正带折射的液态玻璃着色器、Android 与鸿蒙上的字体回落和降级验证、真机性能验证。
