# 歌曲热评

2026-10-09：按用户最新要求，以回退后的 `6e5de36` 为基线，仅实现热评。旧提交中的热评逻辑作参考；不恢复那轮播放器、歌词、设置及全局主题改版。

## 交互

- 正在播放页的原「当前队列」旁增加「歌曲热评」入口，其他布局、字号和播放按钮保持原样。
- 进入后锁定当时的歌曲；网易云音乐、QQ 音乐分开切换，打开或切换时才请求，不阻塞播放。
- 每页20条热评，临近底部提前加载下一页，按评论 ID 去重；失败可重试，保留已读内容和平台阅读位置。
- 应用内展示作者、日期、正文和只读赞数；正文可长按选择。不提供「查看原文」、登录、发评论或点赞操作。
- 沿用现有公共明暗主题，正文无入场动画。支持窄屏、大字号、横屏及长评论。

## 歌曲身份与缓存

- 歌单原始平台 ID、选定 FLAC 音源的平台 ID 仅作为线索；先验证官方歌名、完整版本和歌手，再读取热评。不将布谷YY内部 ID 当作官方 ID。
- 无有效 ID 时搜索官方歌曲；完整歌名/版本、歌手集合相同，已知时长差不超过12秒才接受，相同歌曲优先原专辑。未找到对应版本不拿翻唱或首个结果代替。
- 原歌单与播放音源的完整歌名、歌手均一致时，热评身份核验采用原歌单有效时长，避免《关键词》音源错误时长导致拒绝原曲。已有 ID 详情失败仍允许严格搜索。
- 热评缓存6小时，已核验歌曲映射复用30天；磁盘最多100组首屏，内存最多100组后页。并发同页请求合并，写入串行、原子替换。
- 刷新使旧分页失效，迟到响应不覆盖新结果；刷新失败保留缓存并标记。平台无更多结果、重复整页或 QQ 游标不前进时停止分页。
- 单次网络请求8秒超时；评论请求与歌曲播放独立。不读取用户 cookies 或凭据。

## 接口参考

沿用之前已验证的匿名公开读取方式：网易云 `/api/v1/resource/hotcomments/R_SO_4_{id}` 使用 limit/offset；QQ `music.globalComment.CommentRead/GetHotCommentList` 使用数字 songid、PageNum 和上一页末条 SeqNo。接口失败与没有评论分别提示。

## 验证场景

1. 《演员》《关键词》分别读取两平台热评，下一页追加不同内容，切平台后恢复位置。
2. 翻唱、Live、伴奏和同名不同歌手不串评论；已有 ID 详情失败后仍可搜索。
3. 分页失败重试、并发请求、刷新与旧响应乱序、离线缓存、关闭页面均保持正确状态。
4. 窄屏/大字号/横屏/深色模式无溢出；正文滚动不突然出现或移动已读内容。
5. 手机保留数据覆盖安装 debug 包，播放器、歌词、设置维持回退基线样式。
