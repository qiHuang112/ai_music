# 歌词加载与空状态

2026-10-19用户要求：每次加载歌词时播放器不抖动；区分“暂无歌词”与“加载失败”，确认无歌词时不显示重新加载。

- 同一首歌进入／刷新播放器保留已有歌词，不先清空再显示加载圈；正在进行的同曲请求不重复启动，切歌后的旧结果不能覆盖当前曲。
- 播放页歌词预览在加载、已有歌词、无歌词、失败之间保持稳定高度，按字体缩放预留空间，进度条／播控不随加载上下跳。完整歌词页保留正常跟随及浏览。
- 本地／远端成功返回无歌词或明确不存在：显示“暂无歌词”，不展示重试；网络超时、请求异常或服务异常：显示“歌词加载失败”，保留重试；后续来源成功找到歌词则显示正常歌词，不让较早失败覆盖成功。失败不当作半小时无歌词缓存。
- 验证：有歌词同曲重进、加载前后控件坐标、空结果无重试、异常可重试、失败后恢复、切歌晚到结果、窄屏与大字。


2026-10-19后续反馈：用户新加入歌单后随便连续切换多首歌，普遍先显示“暂无歌词”，切走切回后歌词又出现。按新歌单／新音源／异步预取和缓存更新路径修复，不将尚未准备、未匹配或一次空结果当作确认不存在；晚到的当前曲歌词应自动显示，无需用户切换。确认缺失仍不显示重试，故障仍可重试，避免不断重新请求；保留前轮稳定布局和同曲合并请求，切源／切歌后的旧结果仍必须隔离。

10259实机及用户再次反馈：切到《散场夏天》等已缓存音频后持续“正在获取歌词”，音频正常播放，切走切回才有歌词。继续修复已缓存文件的延迟准备分支，不能只验证首次网络解析；同歌单连续切到已缓存和未缓存的歌曲，歌词均须自动到达，晚到结果不能串歌。

最终体验10261已在77复测：牡丹亭直接下一首散场夏天，从recordReady:false经缓存准备通知到available47行约47毫秒，无需切回。前轮10260连续游子吟／游山恋／春不晚同样自动显示；当前歌词和首曲定位边界在10261实际包已核验。完整结果见[当日记录](worklog/2026-10-19.md)。

2026-11-09用户反馈：有的歌歌词不动，例：局域网备份“Android·17promax”歌单“百听不厌的周杰伦”里的《夜的第七章》。原因：该曲音频来自 BuguYY，缓存歌词是其“介绍”字段的纯文本（`timed: false`，79 行无时间轴），原有“同一酷我音频换带时间轴歌词”的升级对这首没有匹配结果，播放页只能静态显示。修复：缓存歌词无时间轴时（不再限于 BuguYY），在原升级之后按歌曲原始身份（歌单记录的 qq／netease 键、标题、歌手、时长，与热评同一套严格核对）找到网易云同一录音，取其 LRC；只有其中至少六成歌词行与现有纯文本一致才采用，并写回缓存与 `.lrc` 旁文件，失败保留纯文本、之后切回该曲再试。真实接口探针：两条《夜的第七章》（qq:466722、netease:185878）都取到 78 行带时间轴歌词，约 0.4 秒。
